# Упражнение 1. Жёсткие и символические ссылки

Разобраться на практике в разнице между типами ссылок на файл.

1. Создайте обычный файл с текстом внутри.
2. Создайте на него жёсткую ссылку и символическую ссылку с разными именами.
3. Измените содержимое через один из путей и проверьте, что видно через остальные пути.
4. Удалите исходный файл и проверьте, что произошло с каждой из ссылок.
5. Объясните результат, опираясь на то, как устроены ссылки обоих типов.

> **Понадобятся команды:** `ln`, `ln -s`

# Упражнение 2. Контроль целостности файла

Проверить, что файл не был изменён при копировании.

1. Создайте файл среднего размера со случайным или осмысленным содержимым.
2. Вычислите его контрольную сумму одним из стандартных алгоритмов.
3. Скопируйте файл в другое место и вычислите контрольную сумму копии.
4. Сверьте обе суммы автоматически, не сравнивая строки глазами.
5. Измените один байт в копии и покажите, что контрольная сумма изменилась.

> **Понадобятся команды:** `md5sum` / `sha256sum`

4. Посчитайте, сколько раз встречалась каждая строка в исходном файле, без ручного подсчёта.
5. Выведите только те строки, которые встретились более одного раза.

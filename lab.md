# Лабораторная работа №1: Жёсткие и символические ссылки

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_links && cd ~/lab_links
echo "Привет, это исходный файл" > original.txt
ln original.txt hardlink.txt
ln -s original.txt symlink.txt
ls -li
echo "Изменено через жёсткую ссылку" > hardlink.txt
cat original.txt
cat symlink.txt
rm original.txt
ls -li
cat hardlink.txt
cat symlink.txt
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_links` | Создаёт каталог `lab_links` в домашнем каталоге |
| `cd ~/lab_links` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `echo "Привет, это исходный файл" > original.txt` | Выводит строку и перенаправляет её в файл `original.txt` (создаёт файл с текстом) |
| `ln original.txt hardlink.txt` | Создаёт **жёсткую ссылку** `hardlink.txt` на тот же inode, что у `original.txt` |
| `ln -s original.txt symlink.txt` | Создаёт **символическую ссылку** `symlink.txt`, которая хранит путь к `original.txt` |
| `ls -li` | Показывает содержимое каталога подробно (`-l`) с номерами inode (`-i`) |
| `echo "Изменено через жёсткую ссылку" > hardlink.txt` | Перезаписывает содержимое файла через жёсткую ссылку |
| `cat original.txt` | Читает содержимое исходного имени (показывает изменённый текст) |
| `cat symlink.txt` | Читает содержимое через символическую ссылку (показывает тот же текст) |
| `rm original.txt` | Удаляет имя `original.txt` (уменьшает счётчик ссылок на inode на 1) |
| `ls -li` | Снова показывает список файлов с inode — видно, что осталось |
| `cat hardlink.txt` | Читает через жёсткую ссылку — **работает**, данные живы |
| `cat symlink.txt` | Читает через символическую ссылку — **ошибка** `No such file or directory` (битый симлинк) |

---

## Итог (кратко для отчёта)

- **Жёсткая ссылка** (`ln`) — второе имя того же inode. После удаления исходного имени данные остаются доступны через неё.
- **Символическая ссылка** (`ln -s`) — отдельный файл-указатель на путь. После удаления цели становится нерабочей («битой»).

# Лабораторная работа №2: Контроль целостности файла

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_checksum && cd ~/lab_checksum
head -c 1M /dev/urandom > bigfile.bin
sha256sum bigfile.bin
cp bigfile.bin copy.bin
sha256sum copy.bin
sha256sum bigfile.bin copy.bin | awk '{print $1}' | uniq | wc -l
printf '\x00' | dd of=copy.bin bs=1 seek=100 conv=notrunc
sha256sum copy.bin
sha256sum bigfile.bin copy.bin
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_checksum` | Создаёт каталог `lab_checksum` в домашнем каталоге |
| `cd ~/lab_checksum` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `head -c 1M /dev/urandom > bigfile.bin` | Читает 1 мегабайт случайных байт из `/dev/urandom` и сохраняет их в файл `bigfile.bin` (создаёт файл среднего размера со случайным содержимым) |
| `sha256sum bigfile.bin` | Вычисляет контрольную сумму SHA-256 исходного файла и выводит её вместе с именем |
| `cp bigfile.bin copy.bin` | Копирует исходный файл в `copy.bin` (создаёт копию в том же каталоге) |
| `sha256sum copy.bin` | Вычисляет контрольную сумму копии — она должна совпасть с исходной |
| `sha256sum bigfile.bin copy.bin \| awk '{print $1}' \| uniq \| wc -l` | Автоматически сверяет суммы: `sha256sum` считает обе, `awk '{print $1}'` берёт только хеши, `uniq` оставляет уникальные, `wc -l` считает строки. **Результат `1` — файлы идентичны; `2` — различаются** (глазами строки не сравниваем) |
| `printf '\x00' \| dd of=copy.bin bs=1 seek=100 conv=notrunc` | Записывает один нулевой байт в копию на позицию 100: `printf '\x00'` даёт байт, `dd` пишет его в файл `of=copy.bin`, `bs=1` — размер блока 1 байт, `seek=100` — смещение 100, `conv=notrunc` — не обрезать файл после записи. Изменяет ровно один байт |
| `sha256sum copy.bin` | Вычисляет контрольную сумму изменённой копии — она **изменится** по сравнению с исходной |
| `sha256sum bigfile.bin copy.bin` | Ещё раз считает суммы обоих файлов — видно, что хеши теперь разные |

---

## Итог (кратко для отчёта)

- **`sha256sum`** вычисляет криптографический хеш файла. Одинаковые файлы дают одинаковую сумму, любое изменение (даже одного байта) — другую.
- **Автоматическая сверка** без сравнения глазами: `sha256sum file1 file2 | awk '{print $1}' | uniq | wc -l` → `1` значит «идентичны», `2` — «различаются».
- **`dd` + `printf`** позволяют точечно изменить один байт (`seek` — позиция, `conv=notrunc` — не обрезать файл).
- После изменения одного байта контрольная сумма копии **изменилась**, что подтверждает: целостность файла проверена корректно.

# Лабораторная работа №3: Сортировка и уникальные значения

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_sort && cd ~/lab_sort
printf 'banana\napple\ncherry\napple\nbanana\napple\ndate\ncherry\nelderberry\n' > words.txt
sort words.txt > sorted.txt
sort -u words.txt > unique.txt
sort words.txt | uniq -c
sort words.txt | uniq -c | awk '$1 > 1'
wc -l words.txt unique.txt
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_sort` | Создаёт каталог `lab_sort` в домашнем каталоге |
| `cd ~/lab_sort` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `printf 'banana\napple\ncherry\napple\nbanana\napple\ndate\ncherry\nelderberry\n' > words.txt` | Создаёт файл `words.txt` со списком слов в произвольном порядке (есть повторяющиеся строки: `apple` — 3 раза, `banana` — 2 раза, `cherry` — 2 раза) |
| `sort words.txt > sorted.txt` | Сортирует строки по алфавиту и сохраняет результат в новый файл `sorted.txt` (исходный файл не меняется) |
| `sort -u words.txt > unique.txt` | Сортирует и сразу убирает повторы (`-u` = unique), сохраняет в `unique.txt` — только уникальные строки |
| `sort words.txt \| uniq -c` | Сортирует (обязательно, `uniq` работает только с соседними строками) и считает, сколько раз встречается каждая строка: `uniq -c` выводит количество + строку |
| `sort words.txt \| uniq -c \| awk '$1 > 1'` | Из подсчитанного списка оставляет только строки, где счётчик (`$1`) больше 1 — то есть повторы |
| `wc -l words.txt unique.txt` | Считает количество строк в обоих файлах — показывает разницу между исходным (9 строк) и уникальным (5 строк) списками |

**Ожидаемый вывод `uniq -c`:**
```
      3 apple
      2 banana
      2 cherry
      1 date
      1 elderberry
```

**Ожидаемый вывод `awk '$1 > 1'`:**
```
      3 apple
      2 banana
      2 cherry
```

---

## Итог (кратко для отчёта)

- **`sort`** сортирует строки по алфавиту; `sort -u` сразу убирает дубликаты.
- **`uniq`** работает только с **соседними** одинаковыми строками, поэтому перед ним нужен `sort`. `uniq -c` добавляет счётчик вхождений.
- **`awk '$1 > 1'`** фильтрует строки по значению счётчика — оставляет только встречавшиеся более одного раза.
- **`wc -l`** даёт количественную оценку: сколько строк было и сколько осталось после очистки от повторов.

# Лабораторная работа №4: Табличные данные из текста

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_table && cd ~/lab_table
ls -l /usr/bin > listing.txt
ls -l /usr/bin | awk '{print $5, $9}' > cut.txt
ls -l /usr/bin | awk '{print $5, $9}' | column -t > table.txt
seq 1 $(ls -l /usr/bin | wc -l) > numbers.txt
paste numbers.txt table.txt > combined.txt
column -t combined.txt > final_table.txt
cat final_table.txt
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_table` | Создаёт каталог `lab_table` в домашнем каталоге |
| `cd ~/lab_table` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `ls -l /usr/bin > listing.txt` | Получает подробный листинг каталога `/usr/bin` (права, ссылки, владелец, размер, дата, имя) и сохраняет его в `listing.txt` |
| `ls -l /usr/bin \| awk '{print $5, $9}' > cut.txt` | Из листинга оставляет только 5-й столбец (размер в байтах, `$5`) и 9-й столбец (имя файла, `$9`), отбрасывая остальные; сохраняет в `cut.txt`. Эквивалент `cut`, но устойчивее к пробелам в именах |
| `ls -l /usr/bin \| awk '{print $5, $9}' \| column -t > table.txt` | То же, но пропускает через `column -t` — выравнивает столбцы по ширине в аккуратную таблицу; сохраняет в `table.txt` |
| `seq 1 $(ls -l /usr/bin \| wc -l) > numbers.txt` | `wc -l` считает число строк в листинге, `seq 1 N` генерирует последовательность `1..N` — это порядковый номер строки; сохраняет в `numbers.txt` |
| `paste numbers.txt table.txt > combined.txt` | Объединяет два файла построчно в одну таблицу: слева номер строки, справа размер и имя файла (разделитель — TAB) |
| `column -t combined.txt > final_table.txt` | Выравнивает объединённую таблицу по столбцам и сохраняет итог в `final_table.txt` |
| `cat final_table.txt` | Показывает готовую итоговую таблицу на экране |

**Ожидаемый вид итоговой таблицы:**
```
1    4096 2to3-3.10
2    1234 7z
3    5678 7za
...
```

---

## Альтернатива через `cut` (как в задании)

Если нужен именно `cut`, то столбцы `ls -l` фиксированы по позициям:

```bash
ls -l /usr/bin | cut -c1-10,31-40,50- > cut_alt.txt
```

| Команда | Что делает |
|---|---|
| `cut -c1-10,31-40,50-` | Вырезает по символьным позициям: права (1–10), размер (31–40), имя (с 50-го символа). Удобно, но ломается, если размер выходит за диапазон |

---

## Итог (кратко для отчёта)

- **`ls -l`** даёт подробный листинг; нужные столбцы — размер (`$5`) и имя (`$9`).
- **`cut`** / **`awk`** извлекают нужные столбцы; `awk` надёжнее при пробелах в именах.
- **`column -t`** выравнивает вывод в аккуратную таблицу.
- **`seq` + `wc -l`** генерируют порядковые номера строк.
- **`paste`** объединяет два потока построчно в одну таблицу.
- Итог сохранён в **`final_table.txt`** — отдельный файл с готовой таблицей «номер | размер | имя».

# Лабораторная работа №5: Массовая правка текста без редактора

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_sed && cd ~/lab_sed
printf 'hello world\nhello again\n\nhello linux\n\nhello sed\n' > text.txt
sed 's/hello/goodbye/g' text.txt > replaced.txt
sed '/^$/d' replaced.txt > noempty.txt
sed '/^$/d; s/hello/goodbye/g; =' text.txt > numbered.txt
sed -e 's/hello/goodbye/g' -e '/^$/d' -e '=' text.txt > result.txt
cat result.txt
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_sed` | Создаёт каталог `lab_sed` в домашнем каталоге |
| `cd ~/lab_sed` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `printf 'hello world\nhello again\n\nhello linux\n\nhello sed\n' > text.txt` | Создаёт файл `text.txt` с несколькими повторениями слова `hello` и пустыми строками |
| `sed 's/hello/goodbye/g' text.txt > replaced.txt` | Заменяет **все** вхождения `hello` на `goodbye` (`s/.../.../g` — substitute, `g` — global, по всей строке) и сохраняет в `replaced.txt`; исходный файл не трогается |
| `sed '/^$/d' replaced.txt > noempty.txt` | Удаляет все пустые строки (`/^$/` — шаблон пустой строки, `d` — delete) и сохраняет в `noempty.txt` |
| `sed '/^$/d; s/hello/goodbye/g; =' text.txt > numbered.txt` | Одной командой: удаляет пустые строки, заменяет `hello`→`goodbye` и **нумерует** строки (`=` печатает номер перед строкой) |
| `sed -e 's/hello/goodbye/g' -e '/^$/d' -e '=' text.txt > result.txt` | То же самое, но через несколько `-e` (несколько выражений); результат в `result.txt` |
| `cat result.txt` | Показывает итоговый файл на экране |

**Ожидаемый вывод `result.txt`:**
```
1
goodbye world
2
goodbye again
3
goodbye linux
4
goodbye sed
```

> Примечание: `=` выводит номер на отдельной строке. Если нужен номер в одной строке с текстом — это уже `sed '=' | paste - -` или `awk`, но задание требует именно `sed`.

---

## Вариант с номером в одной строке (бонус)

```bash
sed -e 's/hello/goodbye/g' -e '/^$/d' text.txt | sed '=' | paste - -
```

| Команда | Что делает |
|---|---|
| `sed '...' text.txt` | Замена + удаление пустых строк |
| `sed '='` | Печатает номер строки перед каждой |
| `paste - -` | Склеивает пары строк: номер + текст в одну строку |

**Вывод:**
```
1	goodbye world
2	goodbye again
3	goodbye linux
4	goodbye sed
```

---

## Итог (кратко для отчёта)

- **`sed 's/old/new/g'`** — замена всех вхождений в строке (`g` = global).
- **`sed '/^$/d'`** — удаление пустых строк (`/^$/` — пустая строка, `d` — delete).
- **`sed '='`** — нумерация строк прямо в потоке.
- **`-e`** позволяет объединить несколько операций `sed` в одну команду.
- Результат всегда можно перенаправить `>` в новый файл, **не изменяя исходный** — это и есть потоковая правка без интерактивного редактора.

# Лабораторная работа №6: Агрегация данных по столбцам

## Быстрая шпаргалка команд

```bash
mkdir ~/lab_awk && cd ~/lab_awk
printf 'apple 50\nbanana 30\ncherry 120\ndate 75\nelderberry 200\n' > items.txt
awk '{print $2}' items.txt
awk '{sum += $2} END {print "Сумма:", sum}' items.txt
awk 'NR==1 || $2 > max {max=$2; line=$0} END {print "Максимум:", line}' items.txt
awk '$2 > 60' items.txt
```

---

## Отчёт: что делает каждая команда

| Команда | Что делает |
|---|---|
| `mkdir ~/lab_awk` | Создаёт каталог `lab_awk` в домашнем каталоге |
| `cd ~/lab_awk` | Переходит в созданный каталог (меняет текущий рабочий каталог) |
| `printf 'apple 50\nbanana 30\ncherry 120\ndate 75\nelderberry 200\n' > items.txt` | Создаёт файл `items.txt`: в каждой строке имя товара и цена через пробел |
| `awk '{print $2}' items.txt` | Выводит только 2-й столбец (числа) — `$2` это второе поле строки по умолчанию разделённой пробелами |
| `awk '{sum += $2} END {print "Сумма:", sum}' items.txt` | Для каждой строки прибавляет `$2` к переменной `sum`; в блоке `END` (после обработки всех строк) печатает итоговую сумму |
| `awk 'NR==1 \|\| $2 > max {max=$2; line=$0} END {print "Максимум:", line}' items.txt` | На первой строке (`NR==1`) или когда `$2 > max` обновляет `max` и запоминает всю строку `$0`; в `END` печатает строку с максимумом |
| `awk '$2 > 60' items.txt` | Печатает только те строки, где 2-й столбец больше порога 60 (по умолчанию `awk 'условие'` печатает `$0` — всю строку) |

**Ожидаемые выводы:**

`awk '{print $2}'`:
```
50
30
120
75
200
```

Сумма:
```
Сумма: 475
```

Максимум:
```
Максимум: elderberry 200
```

Порог > 60:
```
cherry 120
date 75
elderberry 200
```

---

## Итог (кратко для отчёта)

- **`$1, $2, ...`** — поля строки (по умолчанию разделитель — пробелы); **`$0`** — вся строка; **`NR`** — номер строки.
- **`awk '{sum += $2} END {print sum}'`** — агрегация (сумма) по столбцу.
- **`awk '$2 > max {...} END {...}'`** — поиск максимума с запоминанием строки.
- **`awk '$2 > 60'`** — фильтрация строк по числовому условию.
- Всё выполняется **одной командой** `awk` без промежуточных файлов и ручного подсчёта.
